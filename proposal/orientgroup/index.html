01 / PROJECT DEFINITION

오리엔트가 이미 가진 운영 경험을 하나의 전문 B2B 서비스로 정의하고, 실제 영업과 운영에 사용할 수 있는 브랜드 시스템으로 구축합니다.

사업 구조와 고객에게 전달해야 할 내용을 먼저 이해한 뒤 네이밍과 설명 체계를 정리하고, 그 내용을 시각 아이덴티티와 영업·디지털 접점으로 확장합니다.

01Business Understanding

숙박업 운영 경험, 서비스 구조, 고객 대상과 실제 영업 방식을 파악해 브랜드의 출발점을 정리합니다.

02Brand Definition

네이밍, 버벌 브랜딩, BI와 시각 시스템을 통해 신규 컨설팅 비즈니스의 정체성을 구축합니다.

03Sales & Operation

서비스 설명자료, 영업자료, 홈페이지와 운영 이후 유지보수까지 실제 고객 접점에 브랜드를 적용합니다.

02 / PROJECT PROCESS

사업을 이해하는 단계부터 브랜드를 만들고, 영업 자료와 홈페이지로 실제 사용할 수 있는 형태까지 이어집니다.

각 단계는 분리된 단건 작업이 아니라 앞 단계에서 정리된 내용을 다음 결과물에 연결하며 순차적으로 고도화합니다.

새로운 컨설팅 사례, 프로젝트 성과와 포트폴리오가 발생하면 기존 홈페이지 구조에 맞춰 콘텐츠를 추가·보완합니다.

02 / FUNCTION

기능 보완 및 개선

실제 영업과 운영 중 확인되는 사용성 이슈와 구축 범위 내 경미한 추가 기능·기능 개선을 순차적으로 반영합니다.

03 / STABILIZATION

운영 안정화

오류 수정, 콘텐츠 수정, 레이아웃 보완과 운영상 필요한 경미한 개선을 통해 구축 결과물이 안정적으로 정착하도록 지원합니다.

12 Months
Maintenance
