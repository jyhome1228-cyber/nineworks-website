(주)미궁365
PROJECT
Integrated Rebranding

Verbal → Visual → Application

NINEWORKS

01 / PROJECT DEFINITION

브랜드가 무엇을 말할 것인지 먼저 정의하고, 그 언어를 기준으로 어떻게 보일 것인지 설계합니다.

현재 미궁365가 사용하고 있는 직접적이고 강한 표현은 제품 특징을 빠르게 전달해 온 브랜드 자산입니다. 이번 프로젝트에서는 이를 단순히 부드럽게 바꾸는 것이 아니라, 브랜드의 성격과 제품군 확장을 고려해 메시지의 강도·어조·표현 방식·시각적 활용 기준을 하나의 체계로 정리합니다.

01

Brand Definition

브랜드 기준과 핵심 가치 정리

02

Verbal Foundation

언어 자산과 표현 원칙 구축

03

Visual Translation

언어를 시각 시스템으로 전환

04

Application

패키지·콘텐츠·디지털 적용

05

Operation

실제 활용 및 보완·아카이브

02 / BRAND DEFINITION

기존 자산을 검토하고 앞으로의 브랜드 운영에 필요한 기준을 먼저 설정합니다.

01

Current Brand Review

기존 브랜드, 주요 제품, 상세페이지, 광고, SNS, 공식몰 등 현재 사용 중인 커뮤니케이션과 디자인 자산을 종합적으로 검토합니다.

02

Core Definition

브랜드 핵심 가치, 성격, 태도, 주요 키워드와 제품군 확장 방향을 정리하여 이후 모든 언어와 비주얼 작업의 기준을 설정합니다.

03

Brand Structure

마스터 브랜드와 제품 간 관계, 제품별 메시지의 역할과 고객 접점별 커뮤니케이션 우선순위를 정리합니다.

03 / VERBAL FOUNDATION

비주얼을 만들기 위한 언어적 뼈대를 구축합니다.

미궁365가 어떤 브랜드인지, 어떤 태도로 말해야 하는지, 어떤 단어와 메시지를 반복적으로 사용할지를 먼저 정리합니다. 이 단계에서 구축된 언어 자산은 이후 BI, 패키지, 콘텐츠, 공식몰 등 모든 시각 작업의 방향을 결정하는 기준으로 활용합니다.

Brand Language01

Core Verbal Assets

  • Brand Essence / Brand Keywords
  • Brand Personality / Brand Promise
  • Core Message / Message Hierarchy
  • Short · Medium · Long Brand Description
  • 주요 브랜드 문장 및 핵심 언어 자산
Tone & Voice02

Communication Principles

  • Tone & Voice 기준
  • 헤드라인 및 카피 방향
  • 권장 표현 / 지양 표현
  • 제품 설명 및 상세페이지 표현 기준
  • 광고 · 프로모션 · SNS 언어 기준
Verbal as Foundation

버벌 브랜딩은 별도의 카피라이팅 작업으로 분리하지 않습니다. 정리된 브랜드 언어를 실제 디자인과 콘텐츠에 지속적으로 적용하면서 시각적 시스템과 함께 고도화합니다.

04 / VISUAL TRANSLATION

정립된 브랜드 언어를 시각적 기준으로 번역하고, 모든 접점에서 반복 가능한 시스템으로 정리합니다.

Identity01

Visual Identity System

  • BI / Logo System
  • Brand Color System
  • Typography System
  • Graphic Language / Graphic Motif
  • Image & Photography Direction
Principle02

Visual Consistency

  • Layout Principle
  • Information Hierarchy
  • Digital Visual Direction
  • Print Visual Direction
  • 기본 Visual Guideline

05 / BRAND APPLICATION

구축된 언어와 비주얼 시스템을 실제 브랜드 운영 자료에 적용합니다.

사전에 정해진 몇 개의 결과물만 제작하는 방식보다, 6개월 동안 실제 브랜드 운영에 필요한 항목을 확인하고 우선순위를 협의하여 프로젝트 목적 안에서 최대한 지원합니다.

Package01

Package & Product

  • Master Package Direction
  • 주요 제품 패키지 리뉴얼
  • 제품군별 Variation System
  • 제품 정보 위계 및 메시지 적용 기준
  • 향후 제품 확장용 기본 규칙
Commerce02

Commerce & Contents

  • 상세페이지 디자인 시스템
  • 주요 제품 상세페이지
  • 프로모션 · 배너 · SNS 콘텐츠
  • 광고 및 캠페인 비주얼
  • 운영용 디자인 템플릿
Digital03

Digital Brand Experience

  • 공식몰 주요 Visual Renewal
  • 브랜드 소개 및 콘텐츠 구조
  • 제품 탐색 및 정보 위계 개선
  • 주요 UI Visual Direction
  • 모바일 환경 적용 검토
Application04

Operational Materials

  • 명함 및 기본 인쇄물
  • 패키지 부속물
  • 오프라인 홍보물
  • 브랜드 소개자료
  • 기타 브랜드 운영에 필요한 주요 디자인 자산

06 / SIX-MONTH PROJECT

6개월 동안 정의, 구축, 적용, 보완을 순차적으로 진행합니다.

실제 프로젝트 진행 상황과 제품 출시 및 운영 일정에 따라 단계별 업무는 일부 병행될 수 있습니다.

MONTH 01Analysis & Definition

기존 브랜드 및 자산 분석, 브랜드 핵심 가치와 키워드, 구조와 프로젝트 기준을 정리합니다.

MONTH 02Verbal Foundation

Brand Essence, Core Message, Tone & Voice, 제품·콘텐츠별 언어 기준과 주요 브랜드 문장을 구축합니다.

MONTH 03Visual Identity

버벌 체계를 기준으로 BI, 컬러, 타이포그래피, 그래픽, 이미지 및 레이아웃 시스템을 개발합니다.

MONTH 04Application Build

패키지, 상세페이지, 콘텐츠, SNS, 프로모션 등 주요 브랜드 접점에 시스템을 적용합니다.

MONTH 05Expansion & Operation

공식몰 및 추가 운영 자료로 확장하고, 실제 활용 과정에서 필요한 언어와 비주얼을 함께 보완합니다.

MONTH 06Refinement & Archive

최종 적용 결과를 검토하고 브랜드 가이드, 원본 데이터 및 운영 자산을 정리하여 전달합니다.

07 / WORKING SCOPE

브랜드 구축에 직접 필요한 디자인과 적용 업무를 프로젝트 기간 동안 지속적으로 지원합니다.

01

Flexible Application

초기 단계에서 모든 결과물을 고정하지 않고, 구축된 브랜드 시스템과 실제 운영 상황을 기준으로 필요한 자료를 협의하여 순차적으로 제작합니다.

02

Priority Based

6개월 프로젝트 일정과 업무 리소스 안에서 브랜드 구축에 필요한 항목의 우선순위를 함께 설정하고 가능한 범위에서 최대한 지원합니다.

03

Separate Scope

  • 별도 신규 브랜드 개발
  • 대규모 신규 서비스 · 시스템 개발
  • 대규모 촬영 및 영상 제작
  • 모델 · 스튜디오 · 인쇄 · 제작 실비
  • 유료 폰트 · 스톡 이미지 · 외부 라이선스 및 외주 비용

08 / ORIGINAL DATA & ASSET

프로젝트에서 최종 확정되어 실제 사용되는 브랜드 자산의 원본 데이터를 제공합니다.

미궁365가 프로젝트 종료 이후에도 내부에서 브랜드를 운영하고 확장할 수 있도록 주요 자산을 편집 가능한 형태로 정리해 전달합니다.

Identity Assets

BI·Logo Vector, 컬러, 타이포그래피, 그래픽 및 주요 Visual Asset

Design Source

패키지, 상세페이지, 콘텐츠, 디지털 및 인쇄물의 최종 확정 원본 데이터

Guidelines

Verbal Brand Guide, Visual Brand Guide, Application Guide 및 주요 운영 기준

Original Data

프로젝트 과정에서 제작된 최종 확정 및 실제 사용 디자인 자산은 원본 형태로 제공하는 것을 원칙으로 합니다. 폰트, 스톡 이미지, 플러그인 등 외부 라이선스 자산은 각 라이선스 정책을 따릅니다.

09 / PROJECT MANAGEMENT

진행 상황, 의사결정, 자료와 최종 결과물을 하나의 흐름으로 관리합니다.

Communication01

실무 커뮤니케이션

카카오톡과 이메일을 기준으로 빠른 확인과 피드백을 진행합니다.

Project Hub02

진행 및 자료 관리

일정, 결정사항, 요청 자료, 시안과 최종 결과물을 프로젝트 단위로 정리합니다.

Review03

단계별 검토

주요 브랜드 방향과 결과물은 단계별 검토를 통해 확정하고 이후 적용 범위를 결정합니다.

Archive04

최종 아카이브

확정된 언어, 디자인 자산, 가이드와 원본 데이터를 프로젝트 종료 시점에 정리합니다.
