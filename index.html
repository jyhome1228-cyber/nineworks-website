STRATEGY

What should the brand stand for?

시장과 고객, 사업의 현재 위치를 읽고 브랜드가 어떤 태도와 언어를 가져야 하는지 먼저 정리합니다.

IDENTITY

How should the brand be remembered?

이름, 로고, 컬러, 타이포그래피와 이미지 규칙을 하나의 시각 시스템으로 연결합니다.

EXPERIENCE

Where does the brand come alive?

패키지, 콘텐츠, 공간과 디지털 환경에서 같은 인상이 반복될 수 있도록 실제 접점까지 확장합니다.

BRAND SYSTEM

결과물보다 오래 남는 것은 브랜드의 판단 기준입니다.

브랜드는 런칭 이후에도 계속 선택해야 합니다. 새로운 제품과 콘텐츠, 공간과 채널이 생길 때마다 처음부터 다시 고민하지 않도록 시각과 언어의 원칙을 함께 정리합니다.

무엇을 유지하고 무엇을 바꿀 수 있는지, 이미지와 문장은 어떤 태도를 가져야 하는지, 실제 제작물에서는 어떻게 이어져야 하는지를 하나의 체계로 남깁니다.

NINEWORKS / SINCE 2017

Designing brands as a continuous experience.

나인웍스는 개별 디자인을 만드는 일에서 시작해, 브랜드가 여러 접점에서 같은 인상으로 기억되는 구조를 설계하는 방향으로 작업을 확장해 왔습니다.

지금은 작업의 종류보다 브랜드가 무엇을 남겨야 하는지를 먼저 생각합니다. 브랜드의 방향을 이해하고, 시각 언어를 정리하고, 실제 사용 환경까지 이어지는 흐름을 만듭니다.
