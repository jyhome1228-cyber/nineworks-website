Project

브랜드가 처한 단계와 필요한 디자인의 범위를 살펴보고, 실제 진행한 프로젝트를 통해 나인웍스의 접근 방식과 결과물을 확인할 수 있습니다.

Project Paths

Different stages,
different design needs.

모든 브랜드에 같은 디자인이 필요한 것은 아닙니다. 시작 단계, 개인의 영향력을 브랜드로 확장하는 단계, 성장과 리뉴얼이 필요한 단계, 기업·기관의 체계를 정리하는 단계, 그리고 실제 운영을 위한 디지털 시스템 구축까지 필요한 범위를 다르게 제안합니다.

01

Startup

From idea to identity.

새로운 사업과 브랜드를 처음 시작하는 팀을 위한 프로젝트입니다.

Brand Direction · Naming · Identity · Package · Website · Launch Contents

02

Creator / Influencer

From influence to brand.

개인의 콘텐츠와 영향력을 제품, 서비스, 커머스로 확장하는 프로젝트입니다.

Personal Branding · Product Brand · Package · Commerce Visual · Content System

03

Growing Brand

Make the brand clearer.

운영 중인 브랜드의 시각 체계를 정리하고 성장 단계에 맞게 확장하는 프로젝트입니다.

Brand Renewal · Package Renewal · Website Renewal · Content Guideline · Campaign

04

Company / Organization

Design systems for organizations.

기업과 기관이 여러 채널에서 일관된 이미지를 유지할 수 있도록 디자인 시스템을 구축합니다.

Corporate Identity · Website · Company Profile · IR · Catalog · Event Visual

05

Develop / Digital System

From interface to working system.

브랜드와 기업이 실제 운영에 사용할 수 있는 웹사이트와 디지털 업무 시스템을 기획·디자인·구축합니다.

UX/UI · Website · Quote System · Admin · Firebase · Front-end · Deployment
