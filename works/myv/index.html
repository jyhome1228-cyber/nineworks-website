브랜드와 소비자 참여형 커머스의 관계를 디지털 경험으로 연결하다.

MYV는 브랜드와 브이슈머가 함께 성장하는 가치소비 플랫폼을 소개하는 브랜드입니다. 해당 사이트는 실제 쇼핑몰을 대체하는 결제 서비스가 아니라 브랜드의 비전과 비즈니스, 브이슈머 프로그램, 브랜드 입점, 뉴스 및 문의를 안내하는 기업·브랜드 웹사이트입니다. 이번 프로젝트에서는 기존 브랜드의 정보구조와 메시지를 유지하면서 콘텐츠 전달 방식과 반응형 화면 구성을 재정리하고, 운영자가 브랜드 소식을 관리할 수 있는 기능을 함께 개발했습니다. 주요 콘텐츠를 목적별 페이지로 나누어 이용자의 탐색 경로를 명확하게 하고, 공개 사이트와 운영 관리 시스템을 연결한 점을 핵심으로 정리했습니다.

소비자와 파트너의 서로 다른 방문 목적을 구분하다.

MYV 브랜드 홈페이지에는 일반 소비자뿐 아니라 브랜드 입점을 검토하는 파트너, 브이슈머 프로그램에 관심 있는 참여자, 비즈니스 협력을 원하는 관계자가 방문할 수 있습니다. 이들은 같은 브랜드를 접하더라도 기업의 정체성, 참여 방식, 입점 절차, 최신 소식 중 필요한 정보가 서로 다릅니다. 사이트에서는 About, Business, 브이슈머, 브랜드 입점제안, News와 Contact를 각각 분리하여 이용자의 관심에 맞는 탐색 경로를 제공했습니다. 브랜드의 메시지를 하나로 유지하면서도 대상별로 필요한 콘텐츠의 깊이와 행동 경로를 조정한 것이 중요한 구성 방식입니다. 상업적인 구매 행위는 별도 쇼핑몰 링크와 연결하도록 구분했습니다.

브랜드 설명부터 참여·입점·문의까지 이어지는 다중 페이지.

메인 페이지는 브랜드의 핵심 메시지와 주요 콘텐츠를 소개하는 진입점이며, 상세 페이지는 회사 소개와 비즈니스, 브이슈머, 파트너십, 뉴스, 문의를 담당합니다. 상단 메뉴에는 WITH US 드롭다운을 제공해 브이슈머와 입점제안을 하나의 범주로 연결하면서도 이용자의 목적에 따라 각 페이지로 이동할 수 있습니다. 외부 쇼핑몰인 myv.co.kr은 별도 링크로 안내하여 브랜드 소개 사이트와 실제 상품 구매 경로를 분리했습니다. 국문과 영문 콘텐츠는 독립된 경로와 페이지를 통해 제공하며 콘텐츠별 검색 메타정보 역시 각각 설정되어 있습니다. 이러한 구조는 하나의 브랜드가 소비자·파트너·협력 대상에게 전달해야 할 여러 정보를 정리하는 데 의미가 있습니다.

블루 기반 시각 언어와 콘텐츠 유형별 화면 구성을 결합하다.

MYV 사이트의 시각 시스템은 브랜드 블루를 중심으로 타이포그래피와 비주얼, 주요 행동 버튼을 구성했습니다. 메인에는 로고 중심의 인트로 효과와 대표 비주얼, 브랜드 및 서비스 정보를 결합하고, 서브페이지에서는 내용의 성격에 따라 그리드와 텍스트 블록을 달리 사용합니다. 브랜드 소개는 메시지와 가치 설명에 집중하고 브이슈머와 입점제안 페이지는 이용 흐름과 절차를 설명하는 콘텐츠 구조를 갖습니다. 기존 브랜드의 시각적 인상을 유지하면서도 PC와 모바일에서 글자 크기, 여백, 배치와 CTA의 위계를 보완한 것이 구현상의 주요 내용입니다. 포트폴리오에서는 실제 화면의 완성도를 중심으로 인터페이스 설계 과정을 기록했습니다.

브랜드 콘텐츠를 읽고 다음 행동으로 이어지게 하다.

브랜드 홈페이지의 이용자는 비즈니스 정보를 이해한 뒤 참여 프로그램이나 입점제안을 살펴보고 문의로 이동할 수 있습니다. MYV는 이러한 흐름에 맞춰 각 주제를 독립된 페이지로 제공하며, 뉴스 화면에서는 기업의 최근 활동과 브랜드 관련 소식을 연결합니다. 브이슈머 페이지는 소비자 참여의 의미와 프로그램 구조를 설명하고 입점제안은 브랜드가 검토해야 하는 절차와 기대 역할을 안내합니다. 메인 사이트와 다른 목적을 가진 쇼핑몰은 외부 연결을 통해 분리했으므로 브랜드 탐색과 상품 구매의 맥락을 구별할 수 있습니다. 이처럼 콘텐츠의 주제와 이용자의 행동을 연결한 점이 단순 소개 사이트와 다른 특징입니다.

다양한 접속 환경에서 일관된 브랜드 콘텐츠를 제공하다.

MYV는 데스크톱 내비게이션과 모바일 메뉴, 스크롤 상태에 따른 헤더 변화 등의 인터랙션을 적용했습니다. 화면 크기가 줄어드는 경우 메뉴와 콘텐츠 그리드가 재배치되고 브랜드 이미지와 본문을 다른 비율로 보여주도록 반응형 스타일을 구성했습니다. 사이트에는 영어권 방문자를 위한 /en/ 경로와 각 페이지의 언어별 연결 정보가 포함되어 있습니다. 메인에 구현된 로고 인트로는 세션 내 표시 상태를 관리하고 사용자의 움직임 감소 설정을 고려하도록 구현되었습니다. 방문자의 기기와 언어에 따라 정보 구조가 크게 달라지지 않도록 공통 UI와 콘텐츠 체계를 유지하는 것이 중요한 설계 관점입니다.

정적 웹 기반의 페이지 구조와 UI 동작을 모듈로 구현하다.

MYV 브랜드 홈페이지는 HTML, CSS, JavaScript 기반의 다중 페이지 구조로 개발되었습니다. 메인에서는 세션 저장소를 활용해 로고 인트로가 동일한 브라우징 세션에서 반복적으로 나타나지 않도록 처리하고, 스크립트 실행에 문제가 발생한 경우 콘텐츠 진입을 방해하지 않도록 제한 시간을 둔 예외 동작도 구현했습니다. 공통 script.js는 모바일 메뉴와 드롭다운, 헤더의 스크롤 상태 및 뉴스 관련 사용자 인터랙션을 담당합니다. 콘텐츠별 페이지는 별도의 URL을 유지하며 필요한 화면 요소와 스타일을 결합합니다. 공통 동작과 개별 콘텐츠를 분리한 파일 기반 구조는 브랜드 웹사이트의 반복적인 수정 및 운영을 위한 기반이 됩니다.

브랜드 뉴스와 고객 문의, 방문 기록을 운영 화면으로 연결하다.

MYV 관리자 화면에는 대시보드와 뉴스 관리, 문의 관리, 방문자 관련 기능이 구분되어 있습니다. 관리 스크립트는 GitHub 저장소의 콘텐츠와 변경 상태를 확인하는 처리와 뉴스 목록의 검색·분류·보관·복원, 게시 전 미리보기 등의 화면 동작을 포함합니다. 문의 페이지는 기존 이메일 전송 흐름을 유지하면서 Firebase Firestore에 문의 정보를 기록하는 로직을 함께 갖추고 있습니다. 별도의 방문 기록 스크립트는 공개 브랜드 페이지에서 브라우저 단위의 익명 식별값과 일자, 경로 등의 정보를 저장하도록 구성되어 있습니다. 관리자 전용 데이터와 화면은 외부 포트폴리오에서 직접 노출하지 않고 기능과 아키텍처만 설명합니다.

GitHub 기반 콘텐츠 관리와 Firebase 데이터를 결합한 운영 구조.

사이트 소스는 myvbrand 저장소에서 관리되며 별도 CNAME 파일에는 myvbrand.com 도메인이 설정되어 있습니다. 페이지별 HTML과 공통 스타일, 인터랙션 스크립트를 활용해 콘텐츠를 관리하고 검색 메타정보 및 국·영문 연결 구조를 적용했습니다. 관리자 영역에는 뉴스 콘텐츠 편집과 변경 이력을 다루는 스크립트가 있으며 GitHub API를 활용한 파일 관련 작업도 코드에서 확인됩니다. Firebase Authentication과 Firestore를 이용하는 관리 모듈은 문의 데이터와 방문 기록을 조회하는 데 활용되도록 구성되어 있습니다. 다만 실제 방문자 수나 입점 전환, 판매 성과는 별도 검증 없이 포트폴리오 성과로 기재하지 않고 확인 가능한 구현 구조에 집중합니다.
