01 — PROJECT OVERVIEW

패키지 제작 정보를
하나의 서비스 경험으로 연결하다.

패키지 제작에는 형태, 수량, 규격, 종이, 인쇄 방식, 코팅과 후가공 등 여러 선택이 필요합니다. FINE.B 웹사이트는 고객이 이 정보를 탐색하고 필요한 제작 사양을 순차적으로 정리할 수 있도록 구성된 디지털 접점입니다. 브랜드 소개에서 제작 정보, 견적 요청, 소량 샘플 신청까지 이어지는 사용자 흐름에 주목했습니다.

01 / DISCOVERY

제작 정보의 탐색

박스 유형과 제작 공정, 주문 가이드를 구분하여 사용자에게 필요한 정보를 찾을 수 있도록 구성했습니다.

02 / CONFIGURATION

사양 중심의 견적 흐름

선택 항목을 단계별로 나누어 사용자가 제작 조건을 순서대로 입력하도록 설계한 견적 경험을 제공합니다.

03 / REQUEST

목적별 요청 경로

일반 제작 견적과 소량 샘플 신청을 분리해 서로 다른 이용 목적에 대응하도록 구성했습니다.

03 — SYSTEM DESIGN

선택 과정을 나누면
복잡한 견적도 명확해집니다.

제작 견적 페이지는 다섯 단계의 입력 흐름으로 구성되어 있습니다. 먼저 박스 구조와 규격을 선택하고, 소재와 인쇄, 후가공 조건을 결정한 다음 요청 정보를 전달합니다. 이 화면은 실제 사이트에 구현된 단계 구성을 기준으로 정리했습니다.

STEP 01

박스 형태

구조, 수량, 완성 사이즈

STEP 02

종이 선택

소재와 평량

STEP 03

인쇄

방식, 색상, 인쇄면

STEP 04

코팅·후가공

마감, 박, 패드 등

STEP 05

견적 요청

담당자 및 요청 정보

사용자가 모든 제작 조건을 한 번에 입력하는 대신, 필요한 정보를 각 단계에서 검토하고 선택할 수 있도록 흐름을 조직했습니다. 이와 별도로 소량 샘플 제작 페이지를 제공하여 양산 전 확인을 위한 요청도 받을 수 있도록 했습니다.

04 — EXPERIENCE PRINCIPLES

보여주기 위한 화면을 넘어,
사용하는 웹사이트를 지향합니다.

개별 화면을 아름답게 만드는 것에 그치지 않고, 방문자가 어떤 정보를 이해하고 어떤 행동으로 이어지는지를 고려한 정보 흐름이 중요했습니다. 프로젝트 상세 내용은 실제 개발 자료와 검증된 구현 범위에 맞추어 계속 보완합니다.
