기업의 오랜 제조 경험을 디지털 정보 체계로 재구성하다.

태평제지는 1977년부터 생활 위생용품을 생산·공급해 온 제조기업으로, 제품 제조와 기업 납품, PB 제품 등 서로 다른 사업 영역을 갖고 있습니다. 기업 웹사이트는 이러한 활동을 단편적인 홍보 문장으로 소개하기보다 기업의 역사와 사업 구조를 체계적으로 전달해야 합니다. 이번 프로젝트에서는 기존 기업 콘텐츠를 기반으로 메인 페이지와 사업·제품·기업 정보를 개별 페이지로 정리하고, 실제 이용자가 필요한 정보를 찾아갈 수 있도록 웹사이트의 구조를 재구성했습니다. 기업의 축적된 신뢰와 현재의 사업 활동을 하나의 디지털 접점에서 확인할 수 있도록 하는 데 중점을 두었습니다.

제조기업의 다양한 정보 요구를 사용자 목적에 따라 구분하다.

태평제지 웹사이트의 방문 목적은 일반적인 브랜드 소개에 한정되지 않습니다. 기업의 이력과 운영 역량을 확인하려는 이용자, 생활 위생용품의 제품군을 살펴보려는 거래처, 납품과 제휴를 문의하려는 고객, 채용 정보를 찾는 지원자 등 서로 다른 이용 맥락을 함께 고려해야 합니다. 이에 따라 회사소개와 운영현황, 제품소개, 지속가능경영, 채용, 고객 관련 안내를 독립된 영역으로 분리했습니다. 상세 정보의 순서와 메뉴 이름이 실제 정보 탐색 목적을 반영하도록 구성해 방문자가 기업 콘텐츠의 범위를 이해하고 원하는 정보에 도달할 수 있도록 했습니다.

기업 소개에서 사업 확인과 문의까지 이어지는 다중 페이지 구성.

사이트의 주요 메뉴는 개요, 운영현황, 제품소개, 지속가능경영, 채용, 고객만족, 문의·제휴 등으로 구성됩니다. 회사소개 아래에는 CEO 인사말과 태평제지 스토리, 브랜드, 비전 및 핵심 가치가 연결되며 운영현황은 고객·마케팅·생산·물류·품질로 세분화됩니다. 제품소개에서는 두루마리 화장지부터 점보롤, 페이퍼타월, 키친타월과 미용티슈까지 제품 유형별 상세 경로를 제공합니다. 여러 깊이의 콘텐츠를 단일 화면에 압축하지 않고 목적별 페이지에 배치해 대규모 기업 정보를 분류했습니다. 메뉴의 역할과 페이지 간 연결 관계를 명확히 함으로써 지속적인 콘텐츠 확장에도 대응할 수 있는 구조를 지향했습니다.

브랜드의 인상과 기업 정보의 가독성을 함께 설계하다.

기업 사이트에서는 강한 비주얼 요소와 읽어야 할 정보의 분량 사이에서 균형이 필요합니다. 태평제지의 메인 화면은 기업의 대표 이미지를 전면에 배치하고, 서브페이지에는 안내 제목과 본문, 시각 자료가 역할에 따라 구분되도록 구성되어 있습니다. 특히 사업 현황과 제품 관련 화면은 여러 종류의 정보를 다루기 때문에 카드, 목록, 콘텐츠 블록 등 정보 성격에 맞는 구성 요소를 사용합니다. 기업의 신뢰성을 보여주는 일관된 시각 언어를 유지하면서도 페이지별 콘텐츠에 적합한 화면 구성을 선택하는 것이 중요했습니다. 포트폴리오에서는 실제 완성된 페이지를 중심으로 정보 위계와 배치 방식을 보여줍니다.

서로 다른 기업 콘텐츠를 하나의 사이트 경험으로 연결하다.

방문자가 태평제지의 사업을 이해하는 과정은 한 페이지에서 끝나지 않습니다. 회사소개에서 기업의 이력을 확인하고 운영현황에서 제조·물류·품질에 관한 정보를 살펴본 뒤 제품과 문의 페이지로 이동하는 흐름이 가능합니다. 이를 위해 상단 주요 메뉴와 하위 메뉴를 통해 관련 콘텐츠를 연결하고, 각 페이지에는 해당 주제를 충분히 설명할 수 있는 독립된 영역을 구성했습니다. 제품, 지속가능경영, 채용처럼 목적이 명확한 콘텐츠는 필요한 정보에 직접 접근하도록 경로를 구분했습니다. 화면을 단순히 많이 제작하는 것보다 사이트 전체에서 정보의 관계가 일관되게 유지되도록 하는 데 의미가 있습니다.

다양한 화면 크기에서도 기업 정보의 접근성을 유지하다.

기업의 정보를 탐색하는 사용자는 데스크톱뿐 아니라 태블릿과 모바일에서도 사이트에 접근합니다. 화면 크기가 달라지면 데스크톱의 다단 메뉴와 콘텐츠 그리드를 그대로 유지하기 어렵기 때문에, 좁은 화면에 적합한 내비게이션과 콘텐츠 배치가 필요합니다. 태평제지 웹사이트에는 화면 폭에 따라 데스크톱 메뉴와 모바일 메뉴를 구분하고, 메뉴를 열거나 닫는 자바스크립트 인터랙션이 구현되어 있습니다. 각 서브페이지에서는 콘텐츠 영역의 너비와 이미지 크기 등을 화면에 맞춰 조정하는 스타일 규칙을 사용합니다. 이 섹션은 주요 화면의 실제 반응형 구조를 비교해 정보 탐색이 어떻게 이어지는지 보여줍니다.

페이지별 구조와 공통 인터페이스를 분리해 구현하다.

태평제지 웹사이트는 HTML5, CSS3, Vanilla JavaScript 기반의 여러 정적 페이지로 구성되어 있습니다. 회사·사업·제품 등 개별 경로에 독립된 페이지를 두면서 공통 헤더와 푸터는 별도의 레이아웃 스크립트로 관리할 수 있도록 구현되어 있습니다. 메인 스크립트는 메뉴 열기와 닫기, 스크롤 관련 동작, 페이지별 초기화 등 이용자의 화면 조작을 처리합니다. 제품과 기업 정보처럼 서로 다른 콘텐츠가 다수 존재하는 사이트에서 공통 구성 요소를 반복적으로 수정하는 부담을 줄일 수 있도록 구조를 분리한 점이 중요합니다. 포트폴리오에서는 실제 파일 구성과 화면 동작을 기준으로 프론트엔드 개발의 범위를 설명합니다.

기업 콘텐츠를 검색 가능한 페이지 정보로 구성하다.

다중 페이지 기업 웹사이트에서는 단순한 시각적 구성 외에도 각 페이지가 어떤 정보를 담는지 검색 환경에 전달하는 작업이 필요합니다. 태평제지 사이트에는 페이지별 제목과 설명, canonical URL, Open Graph 속성 등 검색 및 공유 환경을 고려한 메타데이터가 설정되어 있습니다. 메인 페이지에는 Organization과 WebSite 유형의 구조화 데이터가 포함되며, 공통 스크립트에서도 각 콘텐츠 영역에 대응하는 키워드와 설명을 관리합니다. 이는 회사와 제품, 납품 및 기업 활동 관련 정보를 페이지의 목적에 맞게 정리하는 개발 작업입니다. 실제 검색 노출이나 유입 증가 수치는 별도 분석 없이 성과로 제시하지 않고, 구현된 기술적 구성을 중심으로 기록합니다.

정적 사이트 구조와 문의 데이터 처리의 운영 기반.

태평제지 개발 저장소에는 기존 아임웹 기반 콘텐츠를 GitHub Pages 정적 사이트로 전환한 작업 내용이 기록되어 있습니다. 개별 HTML 페이지와 공통 스타일, JavaScript 파일로 구성된 구조는 콘텐츠 수정과 배포 관리가 가능하도록 설계되어 있습니다. 또한 문의·제휴 페이지에는 별도 제출 스크립트가 적용되며, 해당 모듈에서는 Firebase Firestore에 요청 데이터를 등록하기 위한 함수와 제출 완료 안내 인터페이스를 확인할 수 있습니다. 검색 메타데이터와 내비게이션 등 반복 관리되는 구성도 공통 기능으로 분리해 운영 효율을 고려했습니다. 이 섹션에서는 실제 소스에서 확인한 구현 범위를 중심으로 정적 사이트 운영과 데이터 접수 기능을 종합합니다.
