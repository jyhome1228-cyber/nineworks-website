바이오 기술과 전문 케어 브랜드를 연결하는 디지털 플랫폼.

KAISUNCELL은 해양 유래 바이오 소재를 기반으로 두피와 피부 관련 전문 케어 제품을 개발하는 기업입니다. 기업 웹사이트에서는 소재의 연구 배경뿐 아니라 기술이 적용되는 솔루션과 개별 브랜드의 관계를 함께 설명해야 합니다. 이번 프로젝트는 기업 소개와 기술, 제품 개발 방향, 브랜드 및 연구 콘텐츠를 독립된 페이지로 구성한 사례입니다. 방문자가 연구 중심 기업의 특성과 실제 사업 활동을 모두 이해할 수 있도록 콘텐츠의 범위와 정보 위계를 정리했습니다. 기술적 설명과 기업의 방향을 하나의 웹 경험으로 연결하는 것이 주요 구성 목적입니다.

기술 정보와 제품 사업의 차이를 구분하는 콘텐츠 설계.

바이오 기술 기업의 방문자는 소재 연구에 관심 있는 파트너와 제품 및 브랜드의 활동을 확인하려는 고객으로 나뉠 수 있습니다. 이들은 동일한 정보를 읽더라도 기술의 특징, 제품의 적용 영역, 기업의 협력 가능성 중 서로 다른 부분에 주목합니다. 사이트에서는 CTSol-CLRX™의 활용 가능성을 설명하되 세부 원천 제조법은 공개하지 않는 방향을 유지했습니다. 또한 솔루션 시리즈와 브랜드 콘텐츠를 구분하여 기술 개발 방향과 개별 브랜드의 활동이 혼동되지 않도록 했습니다. 이러한 정보 분류는 방문자의 목적에 따라 필요한 내용을 선택적으로 탐색할 수 있도록 돕습니다.

기업·기술·솔루션·브랜드를 연결한 다중 페이지 구조.

사이트는 About, Technology, Solutions, Research, Sustainability, Brands, Contact를 주요 영역으로 구성합니다. Technology에서는 소재 기술의 응용 관점을 설명하고 Solutions는 S-Series, P-Series, B-Series의 전문 관리 영역을 소개합니다. Brands에서는 RECELLÉCLORE와 CLRX를 개별 상세 페이지로 제공하여 기업과 브랜드의 콘텐츠 깊이를 구분합니다. 연구와 지속가능경영은 기업의 기술 기반 및 자원 활용에 관한 별도의 정보 경로를 담당합니다. 공통 메뉴와 브랜드 드롭다운을 통해 서로 다른 정보 영역을 연결한 것이 이 사이트 구조의 핵심입니다.

기술 기업의 신뢰성과 브랜드 콘텐츠의 시각적 일관성을 함께 구현하다.

기업 메인에는 대표 비주얼과 핵심 메시지를 배치하고 회사 소개, 기술, 솔루션, 브랜드, 연구 및 협력 영역으로 이어지는 페이지 흐름을 구성했습니다. 기술 소개는 이미지와 설명 문장을 함께 제시하고 솔루션은 각 적용 영역을 분리한 콘텐츠 구조를 사용합니다. 브랜드 페이지에는 각 브랜드의 시각 자료와 제품 및 케어 분야에 대한 설명을 적용했습니다. 공통 헤더와 푸터, 타이포그래피 및 레이아웃 규칙은 서로 다른 페이지에도 일관되게 사용되도록 설계했습니다. 이 과정에서 전문적인 내용의 가독성과 기업의 시각적 인상을 동시에 고려했습니다.

기술의 사업화 방향과 개별 브랜드를 단계적으로 탐색하다.

카이선셀은 소재 연구의 가능성을 두피·더마·장벽 관련 전문 케어 솔루션과 연결해 설명합니다. 방문자는 기술의 개요를 확인한 뒤 솔루션별 적용 분야를 살펴보고, 관심 있는 브랜드 상세 페이지로 이동할 수 있습니다. RECELLÉCLORE와 CLRX는 각각의 케어 분야를 설명하면서도 기업의 브랜드 포트폴리오 안에서 연결됩니다. 이처럼 회사의 연구 방향과 제품 카테고리, 개별 브랜드를 분리해 구성하면 다양한 사업 활동을 이해하기 쉬워집니다. 특히 개발 방향으로 소개되는 영역과 현재 브랜드 소개를 구분하는 점이 콘텐츠 정확성 측면에서 중요합니다.

언어가 바뀌어도 동일한 정보 탐색 체계를 제공하다.

저장소에는 한국어와 영어, 중국어용 홈페이지 및 여러 서브페이지가 별도의 경로로 구성되어 있습니다. 공통 자바스크립트는 페이지 언어에 따라 메뉴 문구를 변경하고 관련 언어 경로로 연결하는 역할을 담당합니다. 방문자는 같은 기업의 기술과 브랜드를 서로 다른 언어 환경에서 탐색할 수 있습니다. 또한 모바일 메뉴 버튼과 화면 너비별 레이아웃 규칙을 사용해 좁은 화면에서도 기업 정보에 접근할 수 있도록 구현했습니다. 국문과 외국어 페이지를 개별 콘텐츠로 관리하면서 공통 UI 체계를 유지한 점이 특징입니다.

공통 인터페이스를 재사용하는 정적 다중 페이지 구현.

카이선셀 홈페이지는 HTML, CSS, Vanilla JavaScript 기반의 정적 웹사이트입니다. 각 페이지는 독립된 문서로 콘텐츠를 제공하고 main.js는 헤더 및 메뉴, 언어별 경로, 브랜드 드롭다운 등의 공통 동작을 처리합니다. 공통 스타일시트는 메인과 세부 페이지 사이의 시각적 일관성을 유지하도록 구성되어 있습니다. 기업 콘텐츠와 브랜드 콘텐츠를 별도의 URL로 분리한 구조는 새로운 정보를 추가하거나 기존 화면을 수정할 때 변경 범위를 구분할 수 있도록 합니다. 개발 관점에서는 다양한 콘텐츠를 동일한 웹 체계 아래 운영하기 위한 공통 기능 설계가 중요한 부분입니다.

Contact 페이지에서는 별도의 문의 폼과 제출 스크립트를 사용합니다. 해당 코드는 필수 입력값, 이메일 형식과 개인정보 수집 동의 여부를 확인한 후 사용자의 문의 내용을 전송 데이터로 구성합니다. API 주소는 설정 파일이나 전역 변수에서 읽도록 되어 있으며, 주소가 제공되는 경우 서버 엔드포인트에 JSON 요청을 전송합니다. 연결되지 않았거나 오류가 발생한 상황에서는 온라인 접수 상태를 안내하고 이메일 문의 경로를 보여줍니다. 실제 운영 API의 성공 여부와는 별개로 입력 검증, 전송 시도, 오류 대응을 포함한 프론트엔드의 처리 구조를 확인할 수 있습니다.

저장소에는 메인과 회사 소개, 기술, 솔루션, 브랜드, 연구, 지속가능경영, 문의 페이지가 각기 독립된 HTML 문서로 포함되어 있습니다. 국문뿐 아니라 영문과 중문 경로도 별도로 관리하며 공통 스타일과 자바스크립트 모듈을 재사용하는 방식으로 구성했습니다. 저장소 README에는 GitHub Pages 배포를 전제로 한 구조가 기록되어 있고 CNAME 파일에는 kaisuncell.com 도메인이 지정되어 있습니다. 공개 전 콘텐츠 검토, 이미지 사용 및 문의 백엔드 연결의 확인이 필요한 사항으로 적혀 있어 배포 설정과 실제 서비스 운영의 최종 검증은 구분해야 합니다. 이 포트폴리오는 확인 가능한 코드 구성과 웹사이트 설계 범위를 중심으로 정리했습니다.
