농산물 신선도 관리 솔루션을 디지털 경험으로 전달하다.

TerraSAVE는 과일과 농산물의 유통·보관 환경을 고려한 신선도 유지 포장 솔루션을 소개하는 브랜드입니다. 제품의 작동 목적을 이해하려면 단순한 포장재 이미지뿐 아니라 적용 품목, 보관 조건, 시간에 따른 외관 변화 등의 정보를 함께 살펴봐야 합니다. 이번 웹사이트 프로젝트에서는 브랜드의 문제 인식과 제품군, 비교 자료, 도입 및 협력 정보를 여러 페이지로 구분하고 하나의 사용자 경험으로 연결했습니다. 시각 자료를 중심으로 솔루션의 활용 맥락을 전달하면서도 기술과 실제 적용 조건을 확인하려는 기업 고객이 필요한 콘텐츠에 접근할 수 있도록 구성했습니다.

품목과 유통환경이 다른 문제를 한 가지 설명으로 단순화하지 않다.

신선도 유지 포장은 농산물의 종류와 운송 시간, 저장 조건, 포장 단위 등 여러 변수에 따라 요구사항이 달라질 수 있습니다. 따라서 사이트는 하나의 제품이 모든 상황에 동일하게 적용된다는 인상을 주기보다 용기, 보호망, 대형 커버 등의 포장 형태를 구분해 안내합니다. 실제 이용자는 수출을 준비하는 생산자나 유통 관계자, 제품 포장을 검토하는 사업자처럼 서로 다른 목적을 가질 수 있으므로 내용 역시 그 목적에 따라 탐색 가능해야 합니다. TerraSAVE의 페이지 구조는 제품 소개와 품목별 정보를 별도로 구성하고 협력 안내를 제공해 이러한 방문 목적을 폭넓게 다룹니다. 복잡한 보존 관련 정보를 쉽게 이해하도록 배열하는 것이 핵심 과제였습니다.

브랜드 소개에서 제품 검토와 협업 상담으로 이어지는 구조.

웹사이트의 주요 정보는 About TerraSAVE, Product, Freshness Library, Partnership, Why TerraSAVE 및 상담 경로로 구분되어 있습니다. About에서는 솔루션이 필요한 배경을, Product에서는 TerraPACK·TerraShield·TerraCover의 형태를, Freshness Library에서는 과일과 꽃 등 대상 품목별 콘텐츠를 제공합니다. Why TerraSAVE는 고객이 적용 환경에 따라 기대하는 활용 가치를 검토할 수 있는 영역이며 Partnership은 공동 개발이나 제품 공급에 관한 정보로 이어집니다. 각 페이지는 특정 내용을 독립적으로 설명하지만 상단 메뉴와 주요 행동 링크를 통해 다른 영역으로 연결됩니다. 이를 통해 단순한 상품 카탈로그가 아니라 문제 인식부터 제품 이해, 협업 검토까지 이어지는 사이트 체계를 구축했습니다.

실제 비교 자료와 제품 시각 요소가 중심이 되는 화면 구성.

테라세이브의 웹 경험은 제품에 대한 설명과 시각 자료를 함께 다루는 것이 특징입니다. 메인에는 아보카도 보관 비교 시퀀스를 배치하고, 별도의 보관 상태 비교 영역에서는 샤인머스캣, 아보카도, 딸기, 망고, 바나나, 꽃·절화 등 품목별 자료를 전환해 확인하도록 구성했습니다. 제품 영역은 포장 용기와 보호망, 커버를 각각 구분하는 카드와 이미지 중심의 레이아웃으로 제공합니다. 여러 유형의 정보가 한 페이지에 혼재하지 않도록 섹션별 목적을 나누고, 큰 비주얼과 설명 문단, 선택 인터페이스를 배치했습니다. 이 과정에서 실험 사진을 장식 요소가 아니라 사용자가 이해를 돕기 위한 정보 자료로 활용한 점이 중요합니다.

보관 경과 자료를 선택하고 확인하는 인터랙티브 경험.

농산물 보관 비교 자료는 여러 품목과 날짜의 이미지가 축적되기 때문에 한 번에 나열하면 이용자가 비교 대상을 파악하기 어려울 수 있습니다. 메인 페이지에서는 품목별 탭을 제공하고 선택에 따라 해당 콘텐츠 패널을 표시하며, 각 패널에서 경과일과 포장 조건에 따른 이미지를 살펴보도록 구성했습니다. 실제 자바스크립트는 탭의 선택 상태와 연결 패널의 표시 여부를 제어하고 키보드 동작도 처리합니다. 일부 비교 영역에는 사진 확대 및 시간 흐름에 따른 시퀀스 탐색이 구현되어 있습니다. 포트폴리오에서는 이 기능을 통해 정적인 제품 설명을 넘어 여러 보관 비교 자료를 체계적으로 검토하도록 구성한 UX를 보여줍니다.

국문·영문·중문 콘텐츠를 동일한 브랜드 맥락으로 연결하다.

TerraSAVE의 홈페이지에는 한국어와 영어, 중국어로 제공되는 별도의 경로가 마련되어 있습니다. 각 언어별 화면은 브랜드의 포장 솔루션과 비교 자료를 해당 언어로 소개하며, 공통 스크립트에는 현재 페이지와 언어 경로를 고려해 내비게이션을 연결하는 로직이 포함되어 있습니다. 검색 메타정보에도 언어별 대체 페이지가 설정되어 있어 서로 다른 지역의 방문자가 콘텐츠를 찾을 수 있도록 기술적인 기본 구조를 구성했습니다. 또한 화면 폭에 따라 메뉴 동작과 콘텐츠 배치를 조정해 모바일 이용 환경에도 대응합니다. 제품과 실험 관련 정보가 언어와 디바이스에 따라 서로 다른 맥락으로 해석되지 않도록 일관된 탐색 구조를 제공하는 것이 중요합니다.

데이터가 많은 비교 화면을 상태 기반 인터랙션으로 구현하다.

사이트는 HTML, CSS, JavaScript 기반의 다중 페이지 구조이며 공통 탐색 기능과 페이지별 상호작용을 구분해 구현했습니다. 메인 비교 영역에는 home-test-tabs.js가 적용되어 품목별 탭과 연결 패널의 활성 상태를 변경하며, 선택한 탭에 맞춰 화면 내용이 전환됩니다. Why TerraSAVE의 활용 목적별 탭은 별도 스크립트에서 현재 선택 상태와 URL 해시를 관리합니다. 공통 site.js는 헤더와 메뉴 동작, 상담 모달, 콘텐츠 표시 인터랙션 및 언어 경로를 처리하고, 움직임 감소 환경을 고려한 동작 분기도 포함합니다. 이처럼 콘텐츠의 양이 많은 화면에서 사용자 선택에 따른 상태 관리와 공통 기능의 재사용을 함께 고려한 구현 구성이 특징입니다.

기업 고객의 상담 경로와 이용 데이터를 연결하다.

테라세이브 사이트의 상담 경로는 여러 화면에 분산된 단순한 링크를 넘어 공통 스크립트에서 처리하는 상담 인터페이스와 연결되어 있습니다. 실제 contact.html은 별도의 독립 폼을 제공하기보다 메인의 상담 위치로 이동하도록 구성되어 있으며, 공통 기능에서는 상담 관련 링크를 확인하고 상담 모달을 표시하는 로직을 찾을 수 있습니다. 방문 집계는 지정된 운영 도메인에서 외부 분석 API로 페이지 경로를 전송하는 형태로 구성되어 있습니다. 관련 코드에는 쿠키와 방문자 식별정보, 리퍼러를 저장하지 않는 익명 페이지뷰 집계라는 설명이 포함되어 있습니다. 실제 접수 성공률이나 방문 성과는 별도 검증 없이 주장하지 않고, 소스에서 확인된 상담 인터페이스와 집계 연동 구조만 기록합니다.

정적 웹사이트와 다국어 SEO를 기반으로 운영 가능한 구조.

테라세이브 저장소에는 메인과 서비스 소개, 제품, 품목별 콘텐츠, 파트너십, 도입 안내 등 독립된 HTML 페이지가 포함되어 있습니다. 공통 CSS와 페이지별 스타일, JavaScript를 분리하여 보관 비교와 특수 인터랙션 등 화면별 기능을 조정할 수 있도록 구성했습니다. 주요 페이지에는 제목, 설명, canonical URL, 공유 이미지 및 언어별 alternate 링크가 제공되어 콘텐츠의 역할을 검색 환경에 전달하도록 했습니다. CNAME 파일에는 terrasave.co.kr 도메인이 지정되어 있고, 국문·영문·중문 페이지가 별도 경로로 연결됩니다. 본 포트폴리오는 이처럼 구현된 파일 구조와 다국어 콘텐츠 운영 기반, 공통 UI와 분석 API 연동을 중심으로 프로젝트의 기술 범위를 정리합니다.
