02 / About

브랜드를 만들고,
실제 사용되는 장면까지 설계합니다.

나인웍스는 브랜드 전략과 아이덴티티를 중심으로 패키지, 웹사이트, 상세페이지, 콘텐츠, 기업 문서와 실제 제작까지 연결하는 디자인 스튜디오입니다.

브랜드는 하나의 로고나 이미지로 완성되지 않습니다. 제품을 처음 마주하는 패키지, 기업을 소개하는 웹사이트, 고객과 소통하는 콘텐츠, 실제 인쇄물과 제작물까지 서로 다른 접점이 하나의 브랜드처럼 연결되어야 합니다.

각 프로젝트의 목적과 환경을 이해하고 브랜드가 반복해서 사용할 수 있는 시각적 기준을 구축한 뒤, 실제 운영과 제작 환경까지 연결합니다.

Brand Strategy & Identity

신규 브랜드 구축부터 기존 브랜드 리뉴얼까지 브랜드가 시장에서 어떤 위치를 가져야 하는지, 고객에게 무엇을 기억하게 해야 하는지를 먼저 정리합니다.

이후 네이밍, 로고, 컬러, 타이포그래피와 그래픽 시스템을 구축하고 실제 운영에서 반복적으로 활용할 수 있는 가이드로 정리합니다.

Scope

  • Positioning · Core Value · Brand Direction
  • Naming · Slogan · Verbal Branding
  • Logo · Color · Typography · Graphic System
  • Brand Guideline · Application Rule

For

신규 브랜드 런칭, 기존 브랜드 리뉴얼, 제품군 확장, 채널마다 브랜드 인상이 달라진 경우, 내부에서 반복 사용할 기준이 필요한 경우에 적합합니다.

Strategy시장과 고객, 경쟁 브랜드와 제품을 검토하고 브랜드가 가져야 할 핵심 가치와 차별점을 정리합니다.
Verbal브랜드 이름, 슬로건, 소개 문장, 브랜드 톤과 설명 언어를 시각 아이덴티티와 함께 정리합니다.
Identity로고, 컬러, 타이포그래피, 그래픽과 이미지 방향을 하나의 시각 시스템으로 구축합니다.
Guideline패키지, 웹, 콘텐츠와 문서에 적용해도 같은 브랜드처럼 보일 수 있도록 사용 규칙과 마스터 데이터를 남깁니다.
