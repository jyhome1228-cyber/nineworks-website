# NINEWORKS Website

나인웍스 디자인 스튜디오 공식 웹사이트입니다.

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Pages

- `index.html` — Home
- `about.html` — About
- `project.html` — Selected projects
- `project-lorve.html` — Project case study sample
- `portfolio.html` — Visual archive
- `magazine.html` — Magazine
- `contact.html` — Contact

## Local preview

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 확인합니다.

## Content update

현재 프로젝트 이미지는 레이아웃 확인을 위한 그래픽 플레이스홀더입니다. 실제 이미지 파일은 추후 `assets/images/`에 추가하고 각 페이지의 `.project-media` 영역을 교체합니다.
