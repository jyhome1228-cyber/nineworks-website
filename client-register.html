나인웍스와 프로젝트를 진행 중이거나 기존 협업 이력이 있는 회사·브랜드의 클라이언트 등록을 받습니다.

등록 정보를 기준으로 프로젝트 연락처와 회사 정보를 정리하고, 명함 무상 인쇄 요청 등 일부 클라이언트 전용 지원 서비스를 연결합니다. 등록 요청 후 내부 확인을 거쳐 클라이언트 등록 여부를 안내합니다.

easier support.

  • 01
    Client-only Support등록 확인 후 명함 무상 인쇄 요청 등 클라이언트 전용 지원 서비스 이용.
  • 02
    Project Continuity기존 프로젝트와 담당자 정보를 기준으로 후속 디자인·PRINT·DEVELOP 요청 연결.
  • 03
    Updated Contact담당자·회사 정보가 변경된 경우 최신 정보로 다시 등록 요청 가능.
