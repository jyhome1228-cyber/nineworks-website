# NINEWORKS renewal staging

- Live site: https://9works.kr/
- Working preview: https://9works.kr/renewal/
- This directory is an independent first-pass homepage scaffold.
- CSS is isolated under renewal/assets/css. Do not edit root index.html or shared styling during renewal development.
- Meta robots is set to noindex,nofollow,noarchive. This is **not access control**. The preview URL is public to anyone who knows it. Use a protected staging deployment for confidential material.
- Before launch: verify data and claims; build complete internal pages; review navigation; ensure responsive/keyboard accessibility; audit all links; back up live files; check analytics, SEO, redirects and forms.
- Launch should happen only after review, by replacing the root entry points in a controlled change.
